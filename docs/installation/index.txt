============
Installation
============

You use Odevio through your AI agent. Install it once, connect your agent, then just tell the agent what
you want.

**1. Install Odevio** (needs `Python <https://www.python.org/downloads/>`_):

.. code-block::

    pip install odevio

**2. Create your Odevio account:**

.. code-block::

    odevio signup

**3. Connect your AI agent:**

.. code-block::

    odevio skill install

Using Codex, Cursor or Gemini CLI instead of Claude Code? Install into it with ``odevio skill install
--agent codex`` (or ``--agent cursor``, ``--agent gemini``).

That is it. Open your AI agent in your Flutter project's folder and ask it to put your app on your iPhone.

- The :doc:`AI agent guide <../ai_assistant/index>` is the full walkthrough.
- The :doc:`Apple side <../apple/index>` covers the one-time Apple setup your agent will guide you through.

.. note::

    Would rather drive Odevio yourself? You can run the :doc:`command line <../installation_cli/index>`
    directly, or wire it into your :doc:`CI/CD pipeline <../cicd/index>` - but with an AI agent you do not
    need to.
