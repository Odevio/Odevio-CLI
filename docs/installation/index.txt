============
Installation
============

You use Odevio through your AI agent. Install it once, connect your agent, then just tell the agent what
you want.

**1. Install Odevio** (needs `Python <https://www.python.org/downloads/>`_):

.. code-block::

    pip install odevio

**2. Create your Odevio account:**

.. code-block::

    odevio signup

**3. Connect your AI agent.** By default this sets up **Claude Code** - the one integration that also
pre-approves Odevio's commands, so it does not prompt on every step:

.. code-block::

    odevio skill install

Using Codex, Cursor or Gemini CLI instead? Add ``--agent`` (these place the same skill and follow the
agent's own approval rules):

.. code-block::

    odevio skill install --agent codex

Replace ``codex`` with ``cursor``, ``gemini`` or ``universal`` for those - ``universal`` installs under
``.agents/skills``, a location several agents read. Use ``--agent all`` to install for every one at once.
For any other agent that reads the standard, ``--to <its skills directory>`` installs it anywhere.

That is it. Open your AI agent in your Flutter project's folder and ask it to put your app on your iPhone.

- The :doc:`Tutorial <../ai_assistant/index>` shows how to use Odevio once it is set up.
- The :doc:`Apple side <../apple/index>` covers the one-time Apple setup your agent will guide you through.

.. note::

    Would rather drive Odevio yourself? You can run the :doc:`command line <../installation_cli/index>`
    directly, or wire it into your :doc:`CI/CD pipeline <../cicd/index>` - but with an AI agent you do not
    need to.
